# Build a serverless phishing detection system on AWS (Trust Check)

In this workshop you will build Trust Check yourself. It checks a link, an email or a file for signs of phishing, and runs entirely on AWS serverless services. The result is a trust score from 0 to 100, with a reason for every point deducted.
