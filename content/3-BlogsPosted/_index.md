### [Blog 1 - AWS CONTINUUM: BRINGING PENETRATION TESTING INTO EVERY CI/CD DEPLOYMENT](3.1-Blog1/)

This blog explores AWS Continuum for Penetration Testing and how it integrates penetration testing into CI/CD pipelines. It explains change-based testing, OIDC authentication, configurable security gates, and how automated penetration testing can help validate application security before production deployment.
