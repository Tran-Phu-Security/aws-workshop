# Week 9: Monitoring and Logging on AWS

## 1. Work Objectives

- Understand the role of Monitoring and Logging in managing AWS environments.
- Explore Amazon CloudWatch and its main components, including Metrics, Logs, Dashboards, and Alarms.
- Learn how CloudWatch is used to monitor the status and performance of AWS resources.
- Explore Amazon SNS and how it can be used to deliver notifications when alarms are triggered.
- Understand AWS CloudTrail and its role in recording activities within an AWS account.
- Distinguish between the purposes of CloudWatch and CloudTrail.

## 3. Achievements

- Understood the role of Monitoring and Logging in tracking the status, performance, and activities of AWS environments.
- Gained knowledge of the main Amazon CloudWatch components, including Metrics, Logs, Dashboards, and Alarms.
- Understood how CloudWatch Logs organizes log data through Log Groups and Log Streams.
- Learned the purpose of CloudWatch Dashboards in consolidating and visualizing monitoring metrics.
- Understood how CloudWatch Alarms work and how Amazon SNS can be integrated to send notifications when alarm conditions are met.
- Gained an understanding of AWS CloudTrail and its role in recording API activities and supporting account activity reviews.
- Distinguished between CloudWatch, which focuses on monitoring resource performance, status, and logs, and CloudTrail, which records API activities and account events.
- Developed foundational knowledge of monitoring, anomaly detection, and troubleshooting support on AWS.
