# Week 10: Exploring Serverless Architecture on AWS

## 1. Work Objectives

- Understand the concept of Serverless Computing and its fundamental characteristics.
- Learn the role of AWS Lambda in executing code without requiring users to manage servers directly.
- Explore how to create, configure, and manage Lambda Functions.
- Understand Amazon API Gateway and its role in building and managing APIs.
- Learn how to integrate API Gateway with Lambda to process user requests.
- Explore Lambda triggers, execution permissions, and monitoring mechanisms.
- Examine a Serverless application architecture that combines Lambda, S3, and DynamoDB.

## 3. Achievements

- Understood the Serverless Computing model, in which the cloud provider manages the underlying server infrastructure.
- Gained knowledge of AWS Lambda and its role in executing event-driven code without directly managing servers.
- Understood the main components of a Lambda Function, including Runtime, Handler, Execution Role, Timeout, and Memory.
- Learned the purpose of Amazon API Gateway in creating and managing APIs that allow applications and users to send requests to a system.
- Understood how API Gateway integrates with Lambda to process HTTP requests and return responses.
- Learned that Lambda Functions can be triggered by multiple event sources, such as API Gateway and Amazon S3.
- Developed an overview of Serverless architecture combining Lambda, S3, and DynamoDB.
- Understood how CloudWatch supports Lambda monitoring through Logs and Metrics and helps investigate execution errors.
