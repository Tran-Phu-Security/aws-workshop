# Week 8: Exploring CI/CD on AWS

## 1. Work Objectives

- Understand the fundamentals of CI/CD (Continuous Integration and Continuous Delivery/Deployment).
- Understand how CI/CD automates application building, testing, and deployment processes.
- Explore AWS services that support CI/CD, including CodeCommit, CodeBuild, CodeDeploy, and CodePipeline.
- Learn how these services can be integrated into an automated deployment workflow.
- Follow the workshop instructions and examine the operation of a CI/CD pipeline.

## 2. Tasks Performed

| No. | Task Description | Start Date | Completion Date |
|---|---|---|---|
| 1 | Study the concept of CI/CD and the differences between Continuous Integration, Continuous Delivery, and Continuous Deployment. | 02/11/2026 | 02/11/2026 |
| 2 | Explore AWS CodeCommit and its role in managing and storing project source code. | 02/11/2026 | 02/11/2026 |
| 3 | Explore AWS CodeBuild, the build process, and the use of the buildspec.yml file. | 02/11/2026 | 02/11/2026 |
| 4 | Explore AWS CodeDeploy and its mechanism for automatically deploying applications to EC2 instances. | 02/11/2026 | 02/11/2026 |

## 3. Achievements

- Understood the purpose of CI/CD and the benefits of automating software development, testing, and deployment workflows.
- Understood the roles of AWS CodeCommit in source code management, CodeBuild in application building, and CodeDeploy in application deployment.
- Gained an understanding of how AWS CodePipeline coordinates different stages of a CI/CD workflow.
- Understood how CodeCommit, CodeBuild, CodeDeploy, and CodePipeline work together in an application deployment process targeting EC2.
- Learned how to monitor pipeline execution, inspect individual stages, and review error information to support troubleshooting.
- Developed foundational knowledge of automated application deployment on the AWS platform.
