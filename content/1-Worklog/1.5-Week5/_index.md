### Week 5 Achievements:

During the fifth week, I focused on learning Amazon Relational Database Service (RDS), a managed relational database service provided by AWS. Through this learning process, I understood how RDS simplifies the deployment, operation, and management of databases in a cloud environment.

First, I explored the fundamentals of Amazon RDS and the database engines supported by the service, including MySQL, PostgreSQL, MariaDB, and Microsoft SQL Server. I learned that RDS reduces database administration workloads, such as infrastructure setup, backups, and maintenance. I also understood the differences between using RDS and manually installing and managing a database engine on an EC2 instance.

Next, I studied the configuration components of an RDS DB Instance, including Database Engines, Instance Classes, Storage Types, and Allocated Storage. I learned how to select appropriate configurations based on system requirements and explored the differences between Single-AZ and Multi-AZ deployment options. This helped me recognize the role of Multi-AZ deployment in improving availability and supporting database system recovery.

Another important topic was RDS connectivity and security. I explored the relationship between RDS, VPCs, Subnet Groups, and Security Groups in controlling database connections. In particular, I understood the importance of restricting access sources through Inbound Rules and allowing only the necessary systems or clients to connect to the Database Port.

In addition, I studied Amazon RDS backup and recovery features, including Automated Backups, Manual Snapshots, and Point-in-Time Recovery. I learned the differences between these methods and understood the role of Backup Retention Period settings in maintaining the ability to recover data when incidents occur.

Finally, I explored the process of creating and configuring an RDS DB Instance on AWS. The practical learning activities focused on selecting a Database Engine, configuring resources, setting up connectivity, and verifying database operations. I also learned how to create Snapshots, modify configurations, and manage the DB Instance lifecycle to avoid unnecessary resource usage.

By the end of the fifth week, I had developed a clearer understanding of how to deploy and manage relational databases on AWS. The knowledge of RDS, network connectivity, security, and data backups provides an important foundation for building applications with reliable data storage and management capabilities.
