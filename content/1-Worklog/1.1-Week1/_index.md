### Week 1 Achievements:

During the first week, I became familiar with the learning environment and the practical learning approach of the First Cloud AI Journey program. Through the orientation session, I gained an understanding of the learning roadmap, program regulations, and the requirements that need to be completed during the internship.

Through the Cloud Journey materials, I learned the fundamentals of Cloud Computing and gained an overview of Amazon Web Services (AWS). In particular, I understood how AWS organizes its services into major categories such as Compute, Storage, Networking, and Database. These foundational concepts helped me develop a clearer understanding of how cloud services are used to build and operate systems.

In addition to theoretical learning, I practiced creating an AWS Free Tier account and became familiar with the AWS Management Console. I learned how to access the management interface, search for services, and perform basic operations on AWS resources. I also installed and configured AWS CLI on my personal computer using an Access Key, Secret Access Key, and Default Region. After completing the configuration, I executed several basic commands to verify the connection between my local computer and my AWS account.

Regarding Amazon EC2, I studied important concepts such as AMIs, Instance Types, EBS, and Elastic IPs. I then practiced launching an EC2 instance, configuring Security Groups, and connecting to the server through SSH. Additionally, I explored how to attach an EBS Volume to expand the storage capacity of an instance. During the practical exercises, I encountered some difficulties configuring Security Groups and establishing SSH connections. However, by reviewing the configurations and comparing them with the documentation, I gained a better understanding of the causes and solutions to these issues.

By the end of the first week, I had established a foundational understanding of AWS, learned how to use basic management tools, and understood the process of deploying an EC2 instance. These skills and knowledge will serve as a foundation for exploring more advanced AWS services in the following weeks.
