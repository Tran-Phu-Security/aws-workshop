### Week 4 Achievements:

During the fourth week, I focused on learning Amazon Simple Storage Service (S3), an Object Storage service provided by AWS. Through this learning process, I understood the role of S3 in storing, managing, and retrieving data on the cloud platform.

First, I explored the fundamental concepts of Buckets, Objects, Keys, and Regions. I learned that a Bucket is a container for Objects, while an Object is the unit of data stored in S3 and identified through its Object Key. In addition, I studied how to select an appropriate Region for organizing and managing data.

Next, I learned how to create and manage S3 Buckets. I explored the basic configurations required when creating a Bucket and practiced uploading, downloading, and deleting Objects. I also learned how to use Prefixes to organize data logically, making data management and retrieval more convenient.

Another important topic was access control in Amazon S3. I studied Bucket Policies, their JSON structure, and the Block Public Access feature. Through this process, I recognized the importance of configuring appropriate access permissions to reduce the risk of data being accessed or exposed publicly without authorization.

In addition to access control, I explored the S3 Versioning feature. This feature allows multiple versions of an Object to be preserved, making it possible to recover data after accidental changes or deletions. I also studied Delete Markers and how different versions of data are managed within a Bucket.

Finally, I learned about S3 Lifecycle Management, a mechanism that helps automate data lifecycle operations. I understood how to configure Lifecycle Rules to transition Objects between different storage classes or automatically delete data according to predefined conditions. This helped me recognize the importance of Lifecycle Management in optimizing storage costs and managing data over time.

By the end of the fourth week, I had gained foundational knowledge of Amazon S3, including data organization, Bucket and Object management, access control, version preservation, and data lifecycle management. These concepts provide a necessary foundation for exploring other storage and data management services on AWS.
