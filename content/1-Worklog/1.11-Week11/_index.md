# Week 11: Exploring Containerization with Docker and AWS

## 1. Work Objectives

- Understand the concept of Containerization and the role of container technology in application deployment.
- Learn the fundamental components of Docker, including Images, Containers, Dockerfiles, and Docker Engine.
- Explore the process of building Docker Images and running Containers.
- Understand Amazon Elastic Container Registry (ECR) and how it stores and manages Docker Images on AWS.
- Explore Amazon Elastic Container Service (ECS) and its main components, including Clusters, Task Definitions, Tasks, and Services.
- Examine the workflow for deploying containerized applications on AWS by integrating Docker, ECR, and ECS.

## 3. Achievements

- Understood the concept of Containerization and the benefits of packaging applications together with their dependencies in containers.
- Learned the fundamental differences between Containers and Virtual Machines.
- Gained knowledge of Docker Engine, Docker Images, Containers, and Dockerfiles in the process of building, packaging, and running applications.
- Understood the workflow for building Docker Images and running Containers from those Images.
- Learned the purpose of Amazon ECR in storing and managing Container Images on AWS.
- Understood the basic architecture of Amazon ECS and the relationships between Clusters, Task Definitions, Tasks, and Services.
- Developed an overview of the workflow for pushing Docker Images to ECR and using those Images to deploy applications on ECS.
- Understood the importance of monitoring Task and Service status during containerized application operations.
